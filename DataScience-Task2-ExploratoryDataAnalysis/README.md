# Task: Exploratory Data Analysis (EDA) System

## 📌 Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** to uncover key patterns, statistical distributions, correlation matrices, and hidden insights within the dataset. It serves as a foundational step for data cleaning, feature understanding, and preparing data for predictive modeling.

---

## 🛠️ Key Features & Workflow
- **Data Inspection & Cleaning:** Handling missing values, duplicates, and data type conversions.
- **Statistical Summary:** Computing summary statistics (mean, std, min, max, quantiles) for numeric attributes.
- **Univariate Analysis:** Analyzing single variables using histograms, KDE density plots, and bar charts.
- **Bivariate & Multivariate Analysis:** Exploring relationships between features via correlation heatmaps, scatter plots, and pair plots.
- **Outlier Detection:** Identifying anomalies and distribution skews using box plots.
